# SO101 색깔 공 분류: SmolVLA + DSRL 설계

작성일: 2026-10-10

## 1. 목표

MuJoCo 시뮬레이션에서 SO101 로봇이 다음 작업을 반복해서 수행하게 만든다.

1. 제자리(home) 자세에서 자연어 명령을 받는다.
2. 명령된 색의 공을 집어 통에 넣는다.
3. 제자리 자세로 돌아온다.
4. 다음 명령을 기다린다.

단계별 방법은 다음과 같다.

- 스크립트로 만든 시연 데이터로 사전학습된 SmolVLA를 SFT한다.
- 이어서 DSRL로 RL 파인튜닝을 해 성공률을 끌어올린다.
- 최종 목표는 실제 SO101 로봇으로 옮기는 것이다. 그래서 관측·행동 형식은 실제 로봇 데이터셋과 똑같이 맞춘다.

### 성공 기준 (에피소드 1개)

1. 명령된 색의 공이 통 안에 있다. 공 중심이 통 반경 안에 있고, 통 테두리보다 낮아야 한다.
2. 이번 명령을 수행하는 동안 다른 색의 공이 통에 새로 들어가지 않았다. 앞선 명령으로 이미 넣은 공은 판단에서 제외한다.
3. 6개 관절 모두 제자리 자세와의 오차가 5 단위(LeRobot 정규화 단위) 이내다. 시뮬레이션에서는 충돌을 피하려고 wrist_flex만 바꾼 `SIM_HOME_NORM`을 제자리로 쓴다(docs/alignment/NOTES.md 참고). 실제 로봇은 `HOME_NORM`을 쓴다.
4. 900스텝(30초, 30Hz) 안에 끝난다.

### 단계별 통과 기준

| 단계 | 기준 |
|---|---|
| 시연 스크립트 | 성공률 95% 이상이어야 데이터 수집을 시작한다 |
| SFT | 150개 에피소드(색별 50개)에서 성공률 80% 이상 |
| DSRL | 단일 명령 150개 에피소드에서 95% 이상. 3개 명령 연속 수행 시험 50회에서 3개 모두 성공한 비율 85% 이상 |

## 4. 씬과 환경

### 좌표계

- 원점은 로봇 받침 중심이고, z=0이 책상 윗면이다.
- x축은 로봇의 정면(책상 앞쪽), y축은 로봇 기준 왼쪽이다.

### 물체

수치는 사진에서 어림잡은 값이다. 카메라를 보정할 때 함께 확인한다.

| 물체 | 사양 |
|---|---|
| 책상 | 60(가로) × 40(세로)cm, 실제 높이 75cm. 로봇은 뒤쪽 가장자리 중앙에 있다 |
| 통 | 열린 원통. 지름 약 9cm, 높이 약 7cm. 바닥판과 벽 조각 16개로 만들고 반투명으로 표시한다. 중심은 (x=16.5, y=-20.5)cm(로봇 기준 오른쪽, 카메라 화면에서는 왼쪽, 실제 영상으로 보정)이고, 에피소드마다 ±2cm 흔든다 |
| 공 | 빨강·검정·하늘색 3개. 지름 4cm, 질량 약 10g. 스펀지 공이므로 접촉을 약간 부드럽게(solref) 하고 마찰을 높게 설정한다 |

### 카메라

- **주의 (Task 4 확인)**: 실제 데이터셋의 키 이름은 카메라와 반대다. `observation.images.top` = 손목 카메라, `observation.images.front` = 위쪽 카메라. 시뮬레이션도 같은 키 매핑을 쓴다.
- **위쪽 카메라** (MuJoCo 이름 `top`, 키 `observation.images.front`): 책상 앞쪽 가장자리 위에서 로봇 쪽을 비스듬히 내려다본다. 사용자 추정은 책상 위 85cm였으나 영상 보정 결과 책상 위 약 54cm, 시야각 52.5°다 (docs/alignment/NOTES.md).
- **손목 카메라** (MuJoCo 이름 `wrist_cam`, 키 `observation.images.top`): 그리퍼 몸체에 고정한다. 로봇을 정면에서 봤을 때 오른쪽(로봇 자신 기준 왼쪽, +y 쪽) 옆면이고, 집게 끝을 향한다.
- **보정 방법**: 시뮬레이션 렌더링을 실제 데이터셋의 첫 프레임과 겹쳐 비교하면서 카메라 위치와 각도를 조정한다.

### 리셋

- 로봇은 제자리 자세에서 시작하고, 관절마다 ±1 단위의 노이즈를 더한다.
- 공 3개를 무작위로 배치한다.
  - 범위: x ∈ [12, 32]cm, y ∈ [-10, +22]cm
  - 공끼리 7cm 이상, 통과 12cm 이상 떨어뜨린다.
  - 이 범위는 역기구학으로 닿을 수 있는지 검증한 뒤 확정한다.
- 명령은 책상 위에 남아 있는 공 중에서 무작위로 고른다.
- `reset(keep_scene=True)`(연속 명령 모드)는 공 배치를 유지한다. 통에 들어간 공은 그대로 두고, 남은 공 중에서 새 명령을 고른다.

### 단계 진행

- 제어는 30Hz이고, 물리 계산 간격은 2ms다. 따라서 행동 하나당 약 17번 물리 계산을 한다.
- 액추에이터는 menagerie 원본 설정을 그대로 쓴다(STS3215, kp=998.22).

### 미뤄 두는 것

조명·질감·색 무작위화는 실제 로봇 전이 단계에서 다룬다.

## 5. 시연 데이터 생성

### 시연 스크립트 (`expert/scripted.py`)

- 단계: 제자리 → 공 위 10cm(그리퍼 열기) → 공 높이로 하강 → 그리퍼 닫기 → 들어 올리기 → 통 위 8cm → 그리퍼 열기 → 제자리
- 역기구학: MuJoCo 자코비안 기반 감쇠 최소제곱법을 쓴다. 그리퍼는 위에서 아래로 내려 잡는 자세로 고정한다.
- 경로: 최소 저크 보간을 쓴다. 전체 길이는 15~20초다.
- 다양성: 단계별 속도와 경유점에 무작위성을 준다.
- DART 방식: 실행하는 행동에는 작은 노이즈를 섞고, 데이터셋에는 노이즈가 없는 정답 행동을 기록한다.

### 수집 (`data/collect.py`)

- `LeRobotDataset.create()`로 v3 형식으로 저장한다. 특성 이름, 단위, fps, 해상도는 실제 데이터셋과 같다.
- 시연이 실패한 에피소드는 버린다.
- 규모: 색별 200개, 총 600개.
- 먼저 10개만 수집해 영상으로 확인한 뒤 전체 수집을 진행한다.

## 6. SFT

- 시작점: `lerobot/smolvla_base`
- 도구: 설치된 lerobot 0.4.4의 `lerobot-train`을 쓰고, 별도 학습 코드는 만들지 않는다.
- 8GB GPU용 설정:
  - 배치 크기 8로 시작하고, 메모리를 보고 조정한다.
  - 비전 인코더는 고정한다(기본값).
  - bf16 정밀도를 쓴다.
- 학습 길이: 20k~30k 스텝
- 평가: 80%에 못 미치면 실패 영상을 유형별로 분류한다(잘못된 공 선택 / 잡기 실패 / 놓기 실패 / 복귀 실패). 그다음 데이터나 학습 설정을 조정한다.

## 7. DSRL (RL 파인튜닝)

### 구조

- SFT를 마친 SmolVLA 전체를 고정한다.
- 행동 묶음을 생성할 때 쓰는 초기 노이즈를 노이즈 정책이 출력하도록 바꾼다. 원래는 표준정규분포에서 뽑는다.

### 노이즈 정책

- **입력**: SmolVLA 내부의 시각·언어 임베딩(평균 풀링)과 관절값. 둘 다 실제 로봇에서 얻을 수 있다.
- **출력**: 실제로 쓰는 6개 관절 차원 × 행동 묶음 길이 크기의 노이즈.
  - 나머지 패딩 차원은 0으로 둔다.
  - 출력 차원이 너무 커서 학습이 어려우면, 차원을 줄이는 방법을 실험한다.

### 알고리즘

- 노이즈 공간에서 SAC를 쓴다. 행동 묶음 하나를 RL의 한 스텝으로 본다.
- 행동 묶음 중 앞 10스텝만 실행하고 다시 계획한다. 따라서 에피소드 하나는 최대 90번의 RL 스텝이다.

### 보상

| 사건 | 보상 |
|---|---|
| 명령한 공이 통에 들어감 | +1 |
| 다른 공이 통에 들어감 | -1 |
| 최종 성공(제자리 복귀 포함) | +1 |

### 실행

- 환경 8개를 병렬로 돌리고, SmolVLA 추론은 한 번에 묶어 처리한다.
- 학습은 하룻밤 단위를 예상한다.

## 8. 반복 실행 루프 (`run/loop.py`)

- MuJoCo 뷰어 창과 터미널 명령 입력을 함께 쓴다.
- **명령 해석**: 색 키워드를 학습 때 쓴 명령 틀로 바꾼다.
  - 빨강·빨간·red → `red`
  - 검정·검은·black → `black`
  - 하늘색·sky blue → `sky blue`
- **진행 순서**: 대기 → 명령 입력 → 수행 → 성공 판정 → 결과 출력 → 대기
- **예외 처리**:
  - 모르는 색이거나 그 공이 이미 통에 들어가 있으면 안내 메시지만 출력하고 제자리에 있는다.
  - 30초가 지나면 실패를 보고하고, 관절 목표를 제자리 자세로 보내 강제로 복귀시킨다.
