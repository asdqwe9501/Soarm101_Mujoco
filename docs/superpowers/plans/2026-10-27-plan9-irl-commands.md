# Plan 9: IRL 명령 표현 보강 (처음 듣는 표현 일반화)

**배경:**
- IRL v1의 반사실 시험은 기본 표현 96.7%(오선택 0)였지만, 처음 듣는 표현은 87.8%(오선택 6.7%)로 기반(92.2%)보다 낮았다.
- 판별기, 바꿔치기 음성 표본, 정책 학습 명령 모두 학습 표현(train 분할 12종)만 썼다.

**사용자 결정 (2026-10-27):** 표현을 더 다양하게 만들어 시범과 바꿔치기 음성 표본에 넣고 IRL을 다시 학습한다. 평가 전용 표현은 계속 따로 둔다.

## 변경

- `sim/commands.py`
  - `IRL_EXTRA_TEMPLATES` 18종을 추가한다. 평가 전용 3종과 겹치지 않고, 그 동사(get/lift/bring/drop)도 쓰지 않는다.
  - `split="irl"`: 학습 12종 + 확장 18종에서 고르게 뽑는다.
  - SFT용 tier 배분(기본/유사/드문)은 바꾸지 않는다.
- 시범: `irl` 분할로 600 에피소드를 새로 만든다(seed 730000). 바꿔치기 음성 표본은 이 시범에서 만든다.
- 정책 학습 명령: `--commands irl`
- 원본 sft_aux2와 복사본 가중치는 바꾸지 않는다. 다른 설정(β = 1, mismatch 0.5, 2,000 에피소드)은 v1과 같다.

## 관문 (평가 전용 표현으로)

- 맞는 색 시범과 틀린 색 시범을 평가 전용 표현으로 각 100개 만든다(seed 740000).
- 비교:
  - v1 판별기 설정(train 시범): 평가 전용 표현 AUC
  - v2(irl 시범): 평가 전용 표현 AUC
- 학습은 관문 결과와 관계없이 진행한다. 결과는 함께 보고한다.
