# Plan 3: DSRL (노이즈 조종 강화학습) 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** SFT를 마친 SmolVLA(sft_v3)는 고정한다. 행동을 만들 때 쓰는 초기 노이즈를 고르는 작은 정책을 SAC로 학습해, **명령한 색의 공에 잡기를 시도하는 정확도**를 95% 이상으로 끌어올린다. 그다음 단계(잡기, 통에 넣기, 복귀)도 사용자가 정의한 단계별 보상으로 함께 개선한다.

**Architecture:**
- **노이즈 조종 래퍼** `policies/dsrl.py`: SmolVLA의 `predict_action_chunk(batch, noise=...)`에 외부 노이즈를 넣는다. 노이즈 정책이 볼 특징은 SmolVLA 내부의 prefix 임베딩에서 뽑는다.
- **단계별 보상** `rl/staged_reward.py`: 맞는 색 공에 잡기 시도 +1, 잡음 +2, 통에 넣음 +3, 제자리 복귀 +1, 다른 색 공 시도 -1.
- **RL 환경** `rl/chunk_env.py`: 노이즈를 행동으로 받는 Gymnasium 환경. 한 스텝에 행동 묶음 10개를 실행한다.
- **학습기** `rl/sac.py`(SAC)와 `train/dsrl.py`(학습 루프)
- **평가**: 기존 `eval/evaluate.py`와 `tools/counterfactual_eval.py`를 그대로 쓴다.

**Tech Stack:** torch 2.7.1+cu128, lerobot 0.4.4 (SmolVLA), gymnasium 1.3, MuJoCo 3.14

**Spec:** `docs/superpowers/specs/2026-10-10-so101-ballsort-design.md` §7. 사용자 우선순위는 "집기 정밀도보다 색 구분이 더 중요"이다.

## Global Constraints

- 기반 정책: `outputs/train/sft_v3/checkpoints/last/pretrained_model`. 학습하지 않는다.
- SmolVLA 노이즈 모양: `(1, chunk_size=50, max_action_dim=32)`. 실제 관절은 앞 6차원만 쓴다.
- **잠재 행동(노이즈 정책의 출력):** `LATENT_DIM = 50 × 6 = 300`. 나머지 패딩 차원(6~31)은 매 호출마다 표준정규 난수로 채운다(조종하지 않음).
- 잠재 행동 범위: `[-LATENT_SCALE, +LATENT_SCALE]`, `LATENT_SCALE = 2.0`. 표준정규 분포의 주된 범위 안에 머물게 한다.
- RL 한 스텝 = 행동 묶음 중 앞 `EXEC_STEPS = 10`개를 실행하는 것. 에피소드는 최대 900 env 스텝(= 90 RL 스텝)이다.
- 노이즈 정책의 입력은 실제 로봇에서도 얻을 수 있는 것만 쓴다(SmolVLA 내부 임베딩과 관절값). 시뮬레이터 정답 좌표는 보상과 평가에만 쓴다.
- 데이터셋 키, 카메라 매핑, `RENAME_MAP`, `empty_cameras=1`은 Plan 2와 같다.
- 8GB GPU 기준: SmolVLA 추론(약 2GB)과 SAC 네트워크를 함께 올린다. 학습 중에는 다른 GPU 작업을 하지 않는다.
- **사용자 우선순위:** 색 구분이 최우선이다. 집기 실패는 하드웨어로도 보완할 수 있다.

### 잡기 시도 판정 (사용자 정의)

- **시도 시점:** 정책이 내린 그리퍼 명령(행동의 6번째 값, 정규화 단위)이 `GRIP_OPEN_CMD = 40`을 넘은 적이 있고, 그 뒤 처음으로 `GRIP_CLOSE_CMD = 20` 아래로 내려간 순간이다. 실제 집게 위치가 아니라 명령으로 판정하므로, 잡으려는 "의도"를 본다. 판정 후에는 다시 40을 넘어야 다음 시도로 센다.
- **노린 공:** 그 순간 그리퍼 끝(`gripperframe` 사이트)의 높이가 `ATTEMPT_MAX_Z = 0.07`m 이하이다. 또한 수평 거리가 `ATTEMPT_RADIUS = 0.035`m 이내인 공 가운데 가장 가까운 공을 노린 공으로 본다. 공끼리는 최소 7cm 떨어져 있으므로 이런 공은 항상 하나뿐이다. 통에 이미 들어 있는 공은 후보에서 뺀다.
- **놓쳐도 그 공을 잡으려 한 것으로 본다.** 실제로 잡았는지는 따지지 않는다.

### 단계별 보상 (사용자 정의, 각 보상은 에피소드당 한 번)

| 상황 | 보상 | 에피소드 |
|---|---|---|
| ① 명령한 색의 공에 잡기 시도 | +1 | 계속 |
| ② 명령한 색의 공을 잡음 (①을 거친 뒤 공 중심 z > 0.05m) | +2 | 계속 |
| ③ 그 공이 통에 들어감 (②를 거친 뒤) | +3 | 계속 |
| ④ ③ 이후 제자리 복귀 (env의 `at_home()`) | +1 | 종료 (성공, 최대 합계 +7) |
| 다른 색의 공에 잡기 시도 (첫 시도든 재시도든) | -1 | 종료 |
| 다른 색의 공이 들림 (z > 0.05m) 또는 통에 들어감 | -1 | 종료 |
| 첫 시도를 공이 없는 곳에서 함 | -0.5 | 종료 |
| 첫 시도 전에 `ATTEMPT_TIMEOUT_STEPS = 360`(12초) 경과 | -0.5 | 종료 |
| 900 env 스텝 경과 | 0 | truncated |

- 첫 시도가 맞는 공이었다면, 그 뒤 공이 없는 곳에서 다시 닫는 것(재시도)은 벌점 없이 무시한다.
- env 자체 보상(`BallSortEnv.step`의 reward)은 쓰지 않는다. 이 표의 보상만 쓴다.

## Review Focus

1. **잠재 행동이 0이거나 N(0,1)에서 뽑힌 경우**: N(0,1)에서 뽑으면 기반 정책과 같은 분포여야 한다(조종이 없을 때 성능이 떨어지면 안 됨). → Task 1 테스트
2. **에피소드 도중 리셋이나 정책 큐**: `NoiseSteeredSmolVLA`는 SmolVLA 내부 행동 큐(select_action)를 쓰지 않아야 한다. 묶음을 직접 받아 쓴다. → Task 1 테스트
3. **단계 보상이 두 번 들어감**: 같은 단계 보상은 에피소드당 한 번만 받아야 한다. 맞는 공을 놓친 뒤 다시 시도해도 +1을 또 받지 않는다. → Task 2 테스트
4. **잘못된 공 시도가 RL 스텝 중간에 일어남**: 행동 묶음 10개를 실행하는 도중 시도가 나오면 그 env 스텝에서 바로 끝내야 한다. 나머지 행동을 실행하면 안 된다. → Task 2 테스트
5. **학습 중단 후 재개**: 체크포인트에서 actor와 critic을 불러 평가할 수 있어야 한다. → Task 4 테스트

**Interfaces:**
- Consumes:

    - 속성 `.policy`(SmolVLAPolicy), `.pre`, `.post`, `.task`, `._batch(obs)`

    - `predict_action_chunk(batch, noise=None)` (311행 부근)
    - `_get_action_chunk` (274행): 이미지, 언어, 상태를 준비하는 순서
    - `VLAFlowMatching.embed_prefix` (619행): 반환값과 토큰 순서(이미지 → 언어 → 상태)
    - `sample_actions` (794행)
- Produces:
  - 상수 `CHUNK = 50`, `ACT_DIM = 6`, `MAX_DIM = 32`, `LATENT_DIM = 300`, `EXEC_STEPS = 10`
  - `class NoiseSteeredSmolVLA(checkpoint: str, device="cuda", seed=0)`
    - `.reset(env)`: 명령문(`env.task`)을 기억한다.
    - `.features(obs) -> np.ndarray (FEAT_DIM,) float32`: 아래 정의
    - `.chunk(obs, latent: np.ndarray (300,)) -> np.ndarray (50, 6) float32`: 정규화 단위의 관절 목표 묶음
    - 속성 `.feat_dim: int`
    - 속성 `.task: str`(읽기/쓰기): 배치를 만들 때 쓰는 명령문. 내부 `adapter.task`와 같은 값을 가리킨다(property).

**특징 정의 (`features`)**
- `embed_prefix` 출력에서 유효 토큰만 골라 아래를 이어 붙인다. 각 임베딩의 크기는 SmolVLM2 hidden(960)이며, 실제 값은 코드로 확인한다.
  - camera1(손목) 이미지 토큰 평균
  - camera2(위쪽) 이미지 토큰 평균
  - 언어 토큰 평균
  - 정규화된 관절값 6개(전처리기 출력의 `observation.state` 앞 6차원)
- 이미지와 언어 토큰의 위치는 `embed_prefix`가 이어 붙이는 순서와 각 블록의 길이로 계산한다. `empty_cameras=1`로 붙는 빈 카메라 토큰은 제외한다.
- 구현이 복잡하면 `embed_prefix`를 감싸서(monkeypatch) 마지막 호출의 입력과 출력을 잡아 두는 방식을 써도 된다. 이 경우 `features`가 내부적으로 `predict_action_chunk`를 한 번 부르게 되므로, 같은 관측에 대한 `chunk` 호출과 비용이 겹친다. 프레임마다 한 번만 계산되도록 캐시하는 것까지는 하지 않는다.

**노이즈 구성 (`chunk`)**
```python
noise = torch.randn((1, CHUNK, MAX_DIM), generator=self.gen, device=self.device)
noise[0, :, :ACT_DIM] = torch.as_tensor(latent.reshape(CHUNK, ACT_DIM), device=self.device)
actions = self.adapter.policy.predict_action_chunk(self.adapter.pre(self.adapter._batch(obs)), noise=noise)
actions = self.adapter.post(actions)  # (1, 50, 6) 정규화 단위
```
`predict_action_chunk`는 내부 큐를 채우지만 `select_action`을 쓰지 않으므로 무관하다. 다만 `reset()` 때 `self.adapter.policy.reset()`도 함께 호출해 상태를 깨끗하게 둔다.

- [ ] **Step 1: StagedReward 실패 테스트 작성** `tests/test_staged_reward.py`

시연 스크립트를 조종 대상으로 쓴다. 노리는 공을 바꾸려고, `reset()`하는 동안만 `env.target`을 다른 색으로 바꿨다가 되돌린다.

```python
import pytest

from calib import SIM_HOME_NORM
from expert.scripted import ScriptedExpert
from rl.staged_reward import ATTEMPT_TIMEOUT_STEPS, StagedReward
from sim.env import MAX_STEPS, BallSortEnv


def expert_actions(env, seed, aim=None):
    ex = ScriptedExpert(env, seed=seed, dart_sigma=0.0)
    real = env.target
    env.target = aim or real
    ex.reset()
    env.target = real
    return (ex.act()[0] for _ in range(MAX_STEPS))


def run(env, actions_fn, seed=0, target="red"):
    env.reset(seed=seed, options={"target": target})
    sr = StagedReward(env)
    sr.reset()
    total, nonzero, info, n = 0.0, [], {}, 0
    for a in actions_fn(env):
        env.step(a)
        r, done, info = sr.step(a)
        n += 1
        total += r
        if r:
            nonzero.append(r)
        if done:
            break
    return total, nonzero, info, n


@pytest.fixture(scope="module")
def env():
    e = BallSortEnv(render=False)
    yield e
    e.close()


def test_correct_full_sequence_gets_seven(env):
    total, nonzero, info, _ = run(env, lambda e: expert_actions(e, 0))
    assert info["success"] and info["first_attempt"] == "target" and info["stage"] == 4
    assert total == pytest.approx(7.0)
    assert sorted(nonzero) == [1.0, 1.0, 2.0, 3.0]  # 각 단계 한 번씩


def test_wrong_ball_attempt_is_minus_one_and_ends(env):
    total, _, info, _ = run(env, lambda e: expert_actions(e, 0, aim="black"), target="red")
    assert info["first_attempt"] == "other" and info["attempt_color"] == "black"
    assert info["end_reason"] == "wrong_attempt" and total == pytest.approx(-1.0)


def test_no_attempt_times_out(env):
    total, _, info, n = run(env, lambda e: (SIM_HOME_NORM.copy() for _ in range(MAX_STEPS)))
    assert info["end_reason"] == "attempt_timeout" and total == pytest.approx(-0.5)
    assert n == ATTEMPT_TIMEOUT_STEPS


def test_closing_far_from_balls_is_miss(env):
    def open_then_close(e):
        a = SIM_HOME_NORM.copy()
        for g in [60.0] * 30 + [0.0] * 30:
            a[5] = g
```

```python
"""사용자가 정의한 단계별 보상: 맞는 공에 잡기 시도 +1, 잡음 +2, 통에 넣음 +3, 제자리 복귀 +1.

잡기 시도 = 그리퍼 명령이 GRIP_OPEN_CMD를 넘었다가 처음 GRIP_CLOSE_CMD 아래로 내려간 순간.
그 순간 그리퍼 끝 근처(수평 ATTEMPT_RADIUS, 높이 ATTEMPT_MAX_Z 이하)에서 가장 가까운 공이 노린 공이다.
"""

import numpy as np

from sim.env import COLORS

GRIP_OPEN_CMD = 40.0
GRIP_CLOSE_CMD = 20.0
ATTEMPT_MAX_Z = 0.07
ATTEMPT_RADIUS = 0.035
LIFT_Z = 0.05
ATTEMPT_TIMEOUT_STEPS = 360

R_ATTEMPT = 1.0
R_LIFT = 2.0
R_BIN = 3.0
R_HOME = 1.0
R_WRONG = -1.0
R_MISS = -0.5


class StagedReward:
    def __init__(self, env):
        self.env = env
        self.site = env.model.site("gripperframe").id

    def reset(self):
        self.steps = 0
        self.armed = False  # 그리퍼를 연 뒤 아직 닫지 않음
        self.first_attempt = None
        self.attempt_color = None
        self.stage = 0
        self.candidates = [c for c in COLORS if not self.env.ball_in_bin(c)]

    def _aimed_ball(self):
        tip = self.env.data.site_xpos[self.site]
        if tip[2] > ATTEMPT_MAX_Z:
            return None
        d = {c: np.hypot(*(self.env.ball_pos(c)[:2] - tip[:2])) for c in self.candidates}
        c = min(d, key=d.get)
        return c if d[c] <= ATTEMPT_RADIUS else None

    def _info(self, end_reason=None):
        return {
            "first_attempt": self.first_attempt,
            "attempt_color": self.attempt_color,
            "stage": self.stage,
            "success": end_reason == "success",
            "end_reason": end_reason,
        }

    def step(self, action):
        env, target = self.env, self.env.target
        self.steps += 1
        cmd = float(action[5])
        reward = 0.0

        # 잡기 시도 판정
        if cmd > GRIP_OPEN_CMD:
            self.armed = True
        elif self.armed and cmd < GRIP_CLOSE_CMD:
            self.armed = False
            aimed = self._aimed_ball()
            if aimed is not None and aimed != target:
                if self.first_attempt is None:
                    self.first_attempt, self.attempt_color = "other", aimed
                return R_WRONG, True, self._info("wrong_attempt")
            if self.first_attempt is None:
                if aimed is None:
                    self.first_attempt = "none"
                    return R_MISS, True, self._info("miss_attempt")
                self.first_attempt, self.attempt_color = "target", aimed
            if aimed == target and self.stage == 0:
                self.stage = 1
                reward += R_ATTEMPT

        # 다른 공이 들리거나 통에 들어가면 실패
        for c in self.candidates:
            if c != target and (env.ball_pos(c)[2] > LIFT_Z or env.ball_in_bin(c)):
                return reward + R_WRONG, True, self._info("wrong_ball")

        # 단계 보상
        if self.stage == 1 and env.ball_pos(target)[2] > LIFT_Z:
            self.stage = 2
            reward += R_LIFT
        if self.stage == 2 and env.ball_in_bin(target):
            self.stage = 3
            reward += R_BIN
        if self.stage == 3 and env.at_home():
            self.stage = 4
            return reward + R_HOME, True, self._info("success")

        if self.first_attempt is None and self.steps >= ATTEMPT_TIMEOUT_STEPS:
            return reward + R_MISS, True, self._info("attempt_timeout")
        return reward, False, self._info()
```

참고 사항:
- 단계 ②는 단계 ①을 거친 뒤에만 준다. 공이 통 가장자리를 긁으며 z가 잠깐 0.05를 넘는 경우를 막기 위해서다.
- 맞는 공이 잡히지 않고 밀려서 통에 들어가면 ②를 거치지 않았으므로 ③도 주지 않는다. 의도한 동작이다.

```python
import numpy as np

from calib import SIM_HOME_NORM
from expert.scripted import ScriptedExpert
from rl.chunk_env import ChunkEnv
from sim.env import BallSortEnv


class HomeSteer:
    feat_dim = 4

    def reset(self, env):
        self.env = env

    def features(self, obs):
        return np.ones(4, np.float32)

    def chunk(self, obs, latent):
        return np.tile(SIM_HOME_NORM.astype(np.float32), (50, 1))


class ExpertSteer(HomeSteer):
    """latent는 무시하고 시연 스크립트의 실행 행동을 묶음으로 내준다. aim 색을 노린다."""

    def __init__(self, aim=None):
        self.aim = aim

    def reset(self, env):
        self.env = env
        self.ex = ScriptedExpert(env, seed=0, dart_sigma=0.0)
        real = env.target
        env.target = self.aim or real
        self.ex.reset()
        env.target = real

    def chunk(self, obs, latent):
        return np.stack([self.ex.act()[0] for _ in range(50)]).astype(np.float32)

    total, n = 0.0, 0
    while True:
        _, r, term, trunc, info = ce.step(np.zeros(300, np.float32))
        total += r
        n += 1
        if term or trunc:
            return total, info, n
```

```python
"""노이즈(잠재 행동)를 행동으로 받는 RL 환경. 한 스텝 = SmolVLA 행동 묶음 앞부분 실행, 보상 = StagedReward."""

import gymnasium as gym
import numpy as np

from policies.dsrl_constants import EXEC_STEPS, LATENT_DIM, LATENT_SCALE
from rl.staged_reward import StagedReward


class ChunkEnv(gym.Env):
    def __init__(self, env, steer, exec_steps=EXEC_STEPS, latent_dim=LATENT_DIM, latent_scale=LATENT_SCALE):
        self.env, self.steer, self.exec_steps = env, steer, exec_steps
        self.reward_fn = StagedReward(env)
        self.observation_space = gym.spaces.Box(-np.inf, np.inf, (steer.feat_dim,), np.float32)
        self.action_space = gym.spaces.Box(-latent_scale, latent_scale, (latent_dim,), np.float32)
        self._obs = None
        self.last_latent = None

    def reset(self, seed=None, options=None):
        self._obs, info = self.env.reset(seed=seed, options=options)
        self.reward_fn.reset()
        self.steer.reset(self.env)
        self._env_steps = 0
        return self.steer.features(self._obs), info

    def step(self, latent):
        latent = np.clip(np.asarray(latent, np.float32), self.action_space.low, self.action_space.high)
        self.last_latent = latent
        actions = self.steer.chunk(self._obs, latent)
        reward, terminated, truncated, info = 0.0, False, False, {}
        for a in actions[: self.exec_steps]:
            self._obs, _, _, env_trunc, _ = self.env.step(a)
            self._env_steps += 1
            r, done, info = self.reward_fn.step(a)
            reward += r
            terminated = done
            truncated = env_trunc and not done
            if terminated or truncated:
                break
        info["env_steps"] = self._env_steps
        return self.steer.features(self._obs), float(reward), terminated, truncated, info
```

```python
def test_learns_contextual_bandit():
    """특징 부호에 따라 행동 부호를 맞히면 보상 1. 색 선택을 흉내 낸 문제."""

    rng = np.random.default_rng(0)
    sac = SAC(obs_dim=2, act_dim=1, act_scale=2.0, device="cpu", hidden=64, gamma=0.0)
    buf = ReplayBuffer(2, 1, 5000)
    for t in range(3000):

        o = np.array([s, 1.0], np.float32)
        a = sac.act(o)
        r = 1.0 if np.sign(a[0]) == s else 0.0
        buf.add(o, a, r, o, True)
        if len(buf) > 256:
            sac.update(buf.sample(256))
    hits = [np.sign(sac.act(np.array([s, 1.0], np.float32), deterministic=True)[0]) == s for s in (-1.0, 1.0)]
    assert all(hits)
```

- [ ] **Step 3: `rl/sac.py` 구현**

표준 SAC를 구현한다.
- **actor**: tanh로 범위를 제한한 가우시안. 행동 = `act_scale * tanh(u)`, 로그확률에는 tanh 보정을 넣는다.
- **critic**: Q 함수 둘(twin Q)과 각각의 target 네트워크. target은 soft update(tau)로 갱신한다.
- **엔트로피 계수**: α를 자동 조정한다. `target_entropy` 기본값은 `-act_dim`이다.
- **입력 정규화**: actor와 critic 모두 입력 특징 앞에 `nn.LayerNorm(obs_dim)`을 둔다.
- **`deterministic=True`**: `act_scale * tanh(mean)`을 쓴다.
- **save/load**: actor, 두 critic, 두 target critic, log_alpha의 state_dict를 한 파일에 저장한다.

- [ ] **Step 1: 반사실 평가를 "첫 잡기 시도" 기준으로 바꾸기**
  - `tools/counterfactual_eval.py`가 에피소드마다 `StagedReward`를 함께 돌리고, 첫 시도 결과(`first_attempt`, `attempt_color`)로 혼동표를 만든다.
  - 기존의 "처음 들어 올린 공" 기준은 집기 실패를 색 오류와 섞으므로 쓰지 않는다.
  - 에피소드는 첫 시도가 판정되거나 12초가 지나면 끝낸다.
  - 출력 항목:
    - 명령 색별 혼동표
    - 맞는 공 첫 시도 비율(`first_attempt == "target"`)
    - 빗나간 시도(`none`)와 시간 초과 비율
  - 사용법: `--policy {smolvla,dsrl} --checkpoint <sft> [--actor <pt>] --layouts 30 --seed 20000`

- [ ] **Step 2: 기준선과 상한선 측정 (조종 없음)**
  - **기준선**: sft_v3(무작위 노이즈)로 반사실 평가(배치 30개 × 3)를 한다.
  - **상한선** (`tools/dsrl_upper_bound.py`): 같은 장면과 명령에서 `NoiseSteeredSmolVLA`에 N(0,1) 잠재 행동을 8번 넣어 본다. 8번 중 하나라도 첫 시도가 `target`인 장면의 비율을 잰다. DSRL이 도달할 수 있는 상한이다.
  - 상한선이 95% 미만이면 결과를 사용자에게 보고하고 진행 여부를 상의한다.
