# Plan 8: 역강화학습(IRL), sft_aux2 복사본에서 진행

**사용자 결정 (2026-10-18):**
- 역강화학습으로 진행한다. 보상(점수판)을 사람이 주지 않고 시범 데이터에서 거꾸로 추론한 뒤, 그 보상으로 정책을 학습한다.
- 잘 학습된 `sft_aux2`는 메인으로 그대로 둔다. 작업은 복사본(`outputs/train/sft_aux2_irl`)에서 한다.

## 구조 (GAIL 계열 적대적 IRL, 상태 전이 기반)

1. **시범 데이터**
   - 시연 스크립트(전문가)가 시뮬레이션에서 직접 수행한 에피소드를 쓴다.
   - RL 한 스텝(행동 50개) 간격으로 `(s, s')` 특징 쌍을 기록한다. 특징은 `NoiseSteeredSmolVLA.features`로 정책과 같다(손목·위 카메라 임베딩, 명령문 임베딩, 관절 상태).
   - 데이터셋 영상(압축)이 아니라 실시간 렌더를 쓴다. 영상 압축 차이로 판별기가 지름길을 배우지 않게 하기 위해서다.
2. **보상 추론기(판별기)** `rl/discriminator.py`
   - `D(s, s')`: 이 전이가 전문가의 것일 확률. 정책이 아니라 전문가처럼 보이는 정도다.
   - BCE 손실에 전문가 쪽 R1 기울기 벌점을 더한다(과적합 방지).
   - 추론된 보상은 `r = log D(s, s') ≤ 0`이다. 이 실행에서 에피소드를 끝내는 것은 성공(env 판정)뿐이다. 그래서 음수 보상은 "빨리 전문가처럼 끝내라"는 방향이 되고, 생존 편향이 생기지 않는다.
3. **정책**
   - 복사본 SmolVLA는 고정한다. 그 위에서 노이즈를 고르는 KL 정규화 actor-critic(`rl/kl_ac.py`, Plan 7)을 학습한다. 시작 시 정책은 기반 정책과 같다.
   - 450M 모델의 가중치를 직접 RL로 바꾸는 것은 흐름 매칭의 확률 계산이 어렵고 8GB GPU로도 무리다. 그래서 DSRL과 같은 노이즈 공간에서 최적화한다.
4. **번갈아 학습**
   - 에피소드 하나를 실행한다.
   - 판별기를 갱신한다(전문가 쌍 vs 최근 정책 쌍).
   - 리플레이 표본의 보상을 **현재 판별기로 다시 계산**해 actor-critic을 갱신한다.

## 지켜야 할 점

- 사용자 정의 단계별 보상(`rl/staged_reward.py`)은 **학습에 쓰지 않는다.** 기록과 평가에만 쓴다. IRL이 숨은 점수판을 제대로 찾았는지 이것으로 검증한다.
- 에피소드 종료는 env 성공(통 안 + 제자리) 또는 900스텝이다. 단계별 보상의 종료 조건(잘못된 공 시도 등)으로 끝내지 않는다. 종료 시점이 정답 정보를 흘리지 않게 하기 위해서다.
- 판별기 입력은 실제 로봇에서도 얻을 수 있는 특징뿐이다.

## 작업과 관문

1. 복사본 생성, `rl/discriminator.py` + 테스트, `ChunkEnv(staged_termination=False)`
2. `tools/irl_expert_pairs.py`: 전문가 300 에피소드(train 명령문, 무작위화) → `data/irl/expert_pairs.npz`
3. **관문 (보상 복원 확인)**
   - 판별기를 전문가 쌍과 v3 버퍼의 정책 쌍으로 학습한다.
   - 새로 실행한 sft_aux2 에피소드에서 추론 보상을 확인한다. 성공 에피소드 > 잘못된 색 에피소드인지 본다(AUC ≥ 0.8).
   - 통과하지 못하면 정책 학습 전에 사용자에게 보고한다.
4. `train/irl.py` 본 학습(detached) → 평가는 반사실 시험 basic/heldout + 전체 작업이며, sft_aux2와 비교한다.
