## 결론

- **네거티브 시연:** 색 구분이 약한 모델에 "공 앞에서 망설이고 떠나는" 행동을 가르쳤다. 시연을 빼자 공 없는 곳 집기 비율이 24~31%에서 7~10%로 회복됐다.
- **색 오선택:** 모든 시도에서 약 23% 근처에 머물렀다. 학습으로 이 수치를 낮추지 못했다.
- **가장 좋은 모델:** sft_v3다.

## DSRL v3 (sft_aux2 위에서, 2026-10-16~17)

- 상한선: 노이즈 8번 시도 시 맞는 공 도달 100%, 시도 1번당 94.7%였다.
- 학습: 2,000 에피소드, 12차원 조종, 명령문은 학습 배분, 조명·배경 무작위화.
- 학습 곡선: 조종 없는 처음 50개는 성공 94%였다. 학습이 시작되자 24~66%로 떨어졌다.

| 정책 | 반사실 기본 | 반사실 처음 듣는 표현 | 단일 성공 | 연속 3개 모두 |

| DSRL v3 ep1200 | 86.7% | 71.1% | 55.3% | 15% |

**결론:** 기반 모델이 강할 때 현재 방식의 DSRL은 성능을 떨어뜨린다. 결정적 노이즈 선택이 무작위 노이즈보다 나쁘다. DSRL은 세 번 모두 효과가 없었다(v1 붕괴, v2 무효과, v3 악화).

## IRL v1 (sft_aux2 복사본, 2026-10-18~19)

- 방식: 전문가 시범 300개에서 판별기로 보상을 추론한다(GAIL 계열, 상태 전이 기반). 그 보상으로 KL 정규화 노이즈 정책을 학습한다(β = 1).
  - 사용자 정의 단계별 보상은 학습에 쓰지 않았다(기록과 평가에만 사용).
  - 원본 sft_aux2는 바꾸지 않았다.
- 보상 관문(같은 장면에서 맞는 색 시범 vs 틀린 색 시범):
  - 기본 GAIL: AUC 0.54, 실패. 판별기가 색이 아니라 동작 스타일 차이를 배웠다.
  - 명령어 바꿔치기 음성 표본 추가(전문가 움직임 + 다른 색 명령, 판별기 학습에만 사용): AUC 0.89, 같은 장면 99%에서 맞는 색이 더 높았다.
- 학습 곡선(2,000 에피소드, 3시간 15분): 성공률은 78~94% 사이에 머물렀다. 기반 분포에서의 거리(KL)는 0.19였다. DSRL v3와 달리 성능이 무너지지 않았다.

| 정책 | 반사실 기본 (오선택) | 반사실 처음 듣는 표현 (오선택) | 단일 성공 | 연속 3개 모두 |
|---|---|---|---|---|
| sft_aux2 (기반) | 92.2% (3.3%) | 92.2% (3.3%) | 82.0% | 30% |
| sft_aux2 + 색 가드 | | | 87.3% | 40% |
| DSRL v3 최종 | 83.3% (5.6%) | 66.7% (17.8%) | 62.7% | 30% |
| **IRL v1 최종** | **96.7% (0%)** | 87.8% (6.7%) | **90.0%** | **45%** |

- 해석:
  - 기본 표현에서는 오선택이 0이 되었고, 단일·연속 성공도 가장 높았다. 학습 없이 기반에 가드만 붙인 것보다도 높다.
  - 처음 듣는 표현에서는 기반보다 낮다(오선택 3 → 6/90). 판별기와 정책 모두 학습 표현만 봤기 때문으로 보인다.
  - 표본이 작다(반사실 90회). 차이 4~5회는 통계적으로 확실하지 않다.

## IRL v2: 명령 표현 보강 (2026-10-27)

- 변경: IRL 전용 확장 표현 18종을 더해, 시범 600개·바꿔치기 음성 표본·정책 학습 명령에 모두 30종 표현을 썼다. 평가 전용 표현은 따로 두었다.
- 평가 전용 표현 관문:
  - v1 점수판: AUC 0.90, 같은 장면 100%
  - v2 점수판: AUC 0.81, 같은 장면 100%
  - 두 점수판 모두 처음 듣는 표현에서도 색을 구분했다.
- 학습: 2,000 에피소드, KL 0.16~0.19, 성공률 70~92%. 성능이 무너지지 않았다.

|---|---|---|---|---|---|---|
| sft_aux2 | 92.2% (3.3%) | 92.2% (3.3%) | 82.0% (9) | 85.3% (5) | 30% | 30% |
| sft_aux2 + 가드 | | | 87.3% (3) | | 40% | |
| IRL v1 | **96.7% (0%)** | 87.8% (6.7%) | 90.0% (3) | | **45%** | |
| IRL v2 | 92.2% (2.2%) | 90.0% (6.7%) | **92.0% (3)** | 85.3% (4) | 35% | 25% |

- 해석:
  - 처음 듣는 표현에서 오선택은 줄지 않았다(반사실 6/90, v1과 같음). 표현 보강만으로는 처음 듣는 표현의 색 구분이 나아지지 않았다.
  - 기본 표현 단일 성공은 92%로 가장 높다. 남은 실패의 대부분은 잡기 실패다(8/12).
  - v1과 v2의 차이는 모두 표본 오차(90~150회 중 몇 회) 범위다.
