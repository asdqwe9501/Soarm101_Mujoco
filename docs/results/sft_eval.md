# SFT(sft_v1) 평가 결과: 통과 기준 미달

- 단일 명령 150개: 성공률 **0.7%**(1/150)
  - 실패 유형: grasp_fail 140, release_fail 6, wrong_ball 3
- 연속 명령 20회: 0%

## 진단 (systematic debugging)

1. **추론 경로는 정상이다.** 학습 데이터 프레임을 넣으면 정답 행동을 따라간다(관절 평균 오차 0.1~4.9 단위). 같은 seed의 env 관측과 데이터셋 관측의 픽셀 차이는 약 1이다.
2. **학습에 쓴 seed에서도 실패한다.** 일반화 문제가 아니라 폐루프에서 생기는 문제다.
3. **민감도 시험** (같은 노이즈로 첫 행동 묶음을 비교, L1 차이):

   | 바꾼 입력 | L1 차이 |
   |---|---|
   | 명령 red → black (공이 좌우 반대편) | 0.24 |
   | 다른 배치의 영상 | 0.89 |
   | 검은 영상 | 8.2 |

   → 정책이 공 위치와 색 명령을 거의 무시한다.
4. **폐루프 궤적**: 두 번째 행동 묶음부터 공 위치(pan -38)가 아닌 중간 지점(pan -25)으로 가서 내려간다.

## 가설

시연 궤적은 시간에 따라 정해진 매끄러운 궤적이다. 그래서 현재 관절 상태만으로 다음 행동을 거의 예측할 수 있다. 정책이 이 상태 지름길(copycat)을 배워, 영상과 언어로 목표를 찾는 능력을 기르지 못했다.

## 검증 실험

- 관절 상태를 0으로 바꾼 데이터셋(`tools/make_zero_state_dataset.py`)으로 10k 스텝 학습한다(`sft_nostate`).
- 같은 민감도 시험과 소규모 평가로 비교한다.
